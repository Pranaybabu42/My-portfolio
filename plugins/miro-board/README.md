# miro-board (Codex plugin scaffold)

This folder was generated by the `plugin-creator` skill as a starting point for a Miro Board integration.

## What to edit next

- `./.codex-plugin/plugin.json`: replace `[TODO: ...]` placeholders (display name, descriptions, author, URLs, etc.).
- `./.mcp.json`: wire up the MCP server command and set `MIRO_ACCESS_TOKEN`.
- `./skills/`: add one or more skills that describe how to use your Miro tools (optional, but recommended).
- `./scripts/`: implement the MCP server referenced by `./.mcp.json`.

## Marketplace entry

This repo also has a marketplace entry at `/.agents/plugins/marketplace.json` so the plugin can show up in Codex plugin listings once you finish the TODOs.
